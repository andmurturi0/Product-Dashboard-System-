# Projekti Web

Ky është një projekt i zhvilluar në PHP për menaxhimin e produkteve dhe përdoruesve.

## Përdorimi
Për të ekzekutuar projektin, sigurohuni që keni të instaluar XAMPP ose një server të ngjashëm lokal.
Importoni skedarin `projekti.sql` në phpMyAdmin për të konfiguruar bazën e të dhënave.
